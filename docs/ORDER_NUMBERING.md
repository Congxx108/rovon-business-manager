# 订单编号规则与迁移

用户于 2026-10-12 确认 `R2610-001`，授权历史编号、今后取号及订单列宽调整。

## 日常规则

- 编号由 R、订单日期的两位年份/两位月份、至少三位月度流水组成，例如 `R2610-001`、`R2611-001`。
- 每个月独立从 001 开始。补录历史日期使用对应月份下一个可用号，不插入已有流水、不重排已保存订单。
- 首次分配后固定；修改订单日期、金额或发货状态不自动改号。取消/退款不回收，物理删除后的号也保持预留。
- 999 后自然扩展到 1000，不截断、不回到 001。编号可因保留/取消/手动取号出现间隔，不承诺无间断流水。
- 新增页自动显示预计编号，按订单日期读取对应月份 counter 并排除已用/预留号；预显示不占号，自动模式仍提交空值，由保存时的数据库原子取号决定正式编号。可手动修改，清空恢复自动；手填内容不因日期变化或旧预览响应被覆盖。仍保留手工合同号/自定义号入口，手工号不能占用其他订单的新号或旧号，手工短号会推进对应月份 counter。
- 修改日期会重新预览对应月份，未登录不能访问预览，读取失败时可继续由保存自动编号。保存成功显示实际订单号；保存并继续新增重置日期/手填状态，并读取下一预计号。预计号可能因他人先保存而与正式号不同。
- 历史所有编号统一转换；原号保存在 `legacy_order_no`，新旧号都保存在 aliases。原号可用于搜索及旧 CSV 重导入，表格悬停编号可查看原号。
- CSV 有原号/新号均更新对应原订单；空号按原导入键识别后生成短号，重导入该键更新同一订单。一个 CSV 同时包含原单的新旧编号会提示保留一行，避免重复覆盖。
- 订单列表仍按订单日期、创建时间倒序，编号流水不改变列表排序。已有单据/历史 PDF 不重生成，内部 `order_id` 不改变。

## 数据库与上线顺序

1. 备份 orders、order_items、customers、daily_leads、trade_documents、trade_document_versions、trade_document_settings；备份与真实新旧号对照放工作区外私有目录，不提交 Git。
2. 应用 `20261012102757_monthly_order_numbers.sql`：添加兼容列、counter、aliases 与服务端 RPC/触发器；保留原时间编号规则，兼容新程序的空编号保存。此步不转换历史。
3. 部署新程序并确认 Vercel Production 成功，确保 CSV 已按新旧 aliases 解析内部 ID/明细。
4. 应用 `20261012104117_activate_monthly_order_numbers.sql`：在订单表锁与事务内，按订单日期、创建时间、ID 顺序转换历史编号并激活月度取号。只在转换期间暂停 `set_orders_updated_at`，同一事务恢复；订单全部非编号字段/时间戳在提交前逐项检查，否则回滚。
5. 对照迁移前备份验证每个订单 ID/业务字段/时间戳、其他六张业务表与单据/PDF 完整；检查新旧别名、counter 接续、服务端 RPC、权限与线上搜索/筛选/页面。

取号通过单个月份行的 `INSERT ... ON CONFLICT DO UPDATE ... RETURNING` 串行化；手工短号也参与同一月份锁。aliases 使用唯一主键，删除订单只把映射的 order_id 置空，保留号段预留。两张新表启用 RLS，不对 anon/authenticated 开放；新增函数均 SECURITY INVOKER 且固定 search_path，仅服务端 service_role 可执行。

任何回滚应先暂停编号写入、保留新旧号对应表和当前新增记录，再按 ID 恢复备份编号；不能重新导入整份旧 CSV 来回滚，否则会覆盖业务字段。切换后旧页面应刷新到当前发布版本，历史 CSV 文件本身继续兼容。

## 排版范围

仅订单列表使用最大宽度 2240px，其他 AppShell 宽版/默认行为保持原样。2026-10-13 联合优化列宽与内边距：操作 312px、日期/编号各 112px、客户名 200px、联系方式 192px、付款至少 128px、物流单号 176px、取消/退款 120px；其他列宽不变。表格基准最小宽度为 2152px，窄屏操作列 220px 时为 2060px；付款列按最长付款文字增加最低宽度，防止大额定金挤到邻列，启用文字保护时总宽度可相应增加。

表头与内容的左右内边距统一 12px；客户、数量、发货、物流、取消五组起始列左边距 20px，金额与付款边界额外留开，数字右对齐与付款两行保留。全部 16 列、14px 字号、按钮/图标与桌面 68px/手机 114px 行高保留，窄屏继续表格横向滚动。
